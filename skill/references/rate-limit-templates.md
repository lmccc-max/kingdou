# 频率限制提示模板

## 本日工作查询限制
- **每日限制**: 3次/人/天
- **适用场景**: 查询"今天"、"今日"、"本日"的工作记录

## 自定义日期/当月工资查询限制  
- **每日限制**: 1次/人/天
- **每周限制**: 3次/人/周
- **适用场景**: 查询具体日期范围、"本月"、"上周"等非当日查询

## 频率限制配置
- **本日查询限制**: 3次/人/天（仅限查询今日工作）
- **自定义查询限制**: 1次/人/天，3次/人/周（查询历史日期、当月等）
- **重置时间**: 
  - 每日重置：凌晨00:00
  - 每周重置：周一凌晨00:00
- **缓存文件**: `~/.openclaw/workspace/cache/kingdou-rate-limit.json`
- **数据结构**:
```json
{
  "chat_id": {
    "employee_open_id": {
      "today_query": {"date": "YYYY-MM-DD", "count": 2},
      "custom_query": {
        "daily": {"date": "YYYY-MM-DD", "count": 1},
        "weekly": {"week_start": "YYYY-MM-DD", "count": 2}
      }
    }
  }
}
```
